⚙️ First-time setup — complete these steps before using

  1. Create a free project at supabase.com
  2. Go to SQL Editor → paste & run supabase/schema.sql
  3. Open kmc-config.js → replace YOUR_PROJECT_ID and YOUR_ANON_PUBLIC_KEY
  4. In Supabase → Authentication → Users → invite your first admin
  5. In Supabase → Table Editor → admin_users → add a row with that user's auth_id, set role to super_admin
  6. Deploy these files to Netlify (free) or any static host — done!
